# Source notes

Working notes that seeded the literature lattice: cellular sheaves, nonlinear Laplacians, discourse and coordination sheaves, HiSP-style pooling, and the hybrid sheaf-memory prototypes.

The original *Knowledge Sheaves* PDF is not vendored here (size and copyright). Cite Cobb–Gebhart [arXiv:2309.03773](https://arxiv.org/abs/2309.03773) and Hansen–Ghrist from `SOURCES.md`.

These files are references for enhancement — especially the discourse/coordination datasets and the Python harmonic-extension implementations — not runtime code.
